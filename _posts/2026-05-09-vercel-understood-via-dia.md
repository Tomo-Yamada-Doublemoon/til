今日（2026/05/09）はADS第5回講座でした。

テーマはNext.jsとVercel。Next.jsはなんとなく「Reactをベースにしたフルスタックのwebアプリフレームワーク」というのは分かるのですが、Vercelが絡んでくると「で、それはどこで動いてるの？」という疑問が頭に浮かんできました。

Next.jsとセットで語られるのは、Next.jsで作ったアプリをVercelで「ポン」と公開できるから。

> ちなみにVercelはNext.jsを開発した会社でもあります。相性抜群なのは当然といえば当然ですね。
{: .prompt-info }

そこで今回は、普段使っているAIブラウザ「Dia」に丸投げしてみました。

プロンプトはこれ：

> 「Vercelの料金、GitHubとの連携方法、データベースの設置方法、セキュリティの考慮点について、ITにそれほど詳しくない新卒の社会人でもわかるようにわかりやすくまとめてください」

出てきた資料が思ったよりしっかりしていたので、今日の学習メモとして整理してみます。

---

## Vercelって何？

一言でいうと「Webサイトやアプリを、簡単にインターネット上に公開できるサービス」です。

普段私たちが見ているWebサイトは、どこかのサーバー（コンピュータ）の上で動いています。Vercelはそのサーバーの準備や管理を全部やってくれるので、開発者はコードを書くことだけに集中できます。

Node.jsとセットで語られるのは、Node.jsで作ったアプリをVercelで「ポン」と公開できるから。**コードを書いてGitHubに上げたら、サイトが自動で更新される**というのが最大の魅力です。

---

## 料金プランは3段階

| プラン | 料金 | 向いている人 |
|---|---|---|
| Hobby（無料） | ¥0 | 個人の勉強・ポートフォリオ |
| Pro | 約¥3,000/月 | 仕事・チーム開発 |
| Enterprise | 要相談 | 大企業・ミッションクリティカルなサービス |

> 無料プランでも、月100万アクセス対応・CDN自動有効・ファイアウォール標準装備・画像最適化（月5,000枚）がついてきます。個人学習には十分すぎるスペックです。
{: .prompt-tip }

> Hobbyプランは**商用利用不可**です。お金を稼ぐ目的のサービスには使えません。
{: .prompt-warning }

---

## GitHubとの連携は4ステップ

GitHubは「コードのGoogleドライブ」のようなもの。Vercelはこれと直接つながります。

1. Vercelにログインして「New Project」をクリック
2. GitHubアカウントを選択（初回は「Add GitHub Account」で接続）
3. 公開したいリポジトリ（コードの保管庫）を選ぶ
4. 「Deploy」ボタンを押す → 数十秒でサイトが公開される

**つないだ後の動き：**
- `main`ブランチにコードを送ると**自動で本番に反映**される
- プルリクエスト（変更の提案）を出すと**専用URLが自動生成**される（本番に影響なしで動作確認できる）
- 問題が起きたらワンクリックで**前の状態に戻せる（ロールバック）**

---

## データベースはMarketplaceから接続する

Vercel自体にデータベースは内蔵されていません。「Storage」タブから外部サービスを選んで接続します。

| サービス | ひとことで | 無料枠 |
|---|---|---|
| **Neon** | シンプル、初心者向け | 0.5GB |
| **Supabase** | DB＋ログイン機能＋リアルタイムがセット | 500MB |
| **Prisma Postgres** | コードからDBを操作するツールと相性抜群 | あり |

> 迷ったら**NeonかSupabase**を選べばOK。どちらも無料枠があります。
{: .prompt-tip }

画像・ファイルの保存には、Vercel内蔵の「Blob Storage」が使えます（無料プランで1GBまで）。

---

## セキュリティ：Vercelが守る部分と自分で守る部分

**Vercelが自動で守ってくれること：**
- HTTPS（通信の暗号化）
- DDoS対策（大量アクセス攻撃の自動ブロック）
- ファイアウォール（不正アクセスの遮断）

**自分で気をつけること：**

> APIキー（外部サービスのパスワードのようなもの）は「環境変数」に保存し、コードに直接書かないこと。GitHubに上げると世界中から見られてしまいます。
{: .prompt-danger }

> 開発中のサイトのURLにはパスワードをかけておきましょう。そのまま放置すると未完成の機能が誰でも見られる状態になります。
{: .prompt-warning }

VercelはSOC 2 Type 2・ISO 27001という国際的なセキュリティ認証を取得済み。「第三者機関が監査して合格した」という証明なので、大企業が採用する際の安心材料にもなります。

## 今日の雑感

Next.js＋Vercelの組み合わせは、「コードを書いてGitHubに送るだけで、世界に公開される」という体験を最短距離で実現してくれる仕組みだと理解しました。

> Node.jsとNext.jsは「名前が似ているだけの別物」です。Node.jsはJavaScriptをサーバー側で動かす実行環境、Next.jsはその上で動くWebアプリのフレームワーク。土台と建物くらい違います。
{: .prompt-tip }

インフラの知識がなくても動かせる設計になっているのが現代っぽいなと感じつつ、セキュリティの「自分で守る部分」はちゃんと意識しないといけない、という当たり前だけど大事な学びもありました。

Diaへの丸投げが思ったより有効だったので、今後も「わからん」と思ったらAIに聞いて資料化→自分の言葉で再整理、というフローを定着させていこうと思います。

---

💡 **OHOポイント:** VercelはNode.jsアプリを「公開する場所」を提供するだけでなく、GitHubとの連携で「コードを書いたら即反映」という開発体験ごと変えてしまうサービスでした。「サーバー管理」という概念が消えている感覚が新鮮です。

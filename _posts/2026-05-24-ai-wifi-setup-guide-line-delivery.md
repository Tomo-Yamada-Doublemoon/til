## この記事でわかること

- GenSparkのAIチャット＋スーパーエージェントで図解を作る6ステップの流れ
- ファクトチェックを挟む「ズレないプロンプト設計」の実例
- 専門知識ゼロの方へ届けるための「LINEファースト設計」の考え方

## こんな人向け

家族や知人へ、技術的な手順を分かりやすく届けたいフリーランス・ITサポート役の方

## 前提

- 使ったツール: GenSpark（AIチャット＋スーパーエージェント）
- OS / 環境: ブラウザのみ
- 課題フェーズ: 個人のITサポート（ADS課題外）

---

## きっかけ

家族から連絡がありました。

「回線が変わったあと、スマホとパソコンの設定がよくわからなくて…」

電話口での説明は伝わりにくいです。訪問は時間がかかります。
ならば**図解をLINEで送る**、これが一番早いと判断しました。

ただし一から自分で作るのは手間がかかります。ここでGenSparkを使うことにしました。

---

## やったこと：プロンプト6本の流れ

### ① 基本情報をAIチャットでまとめる

まずGenSparkのAIチャットに投げました。

```
Nuro光への回線切り替え後のWi-Fi設定方法を、
SAMSUNGのAndroidスマホとWindowsパソコン用でまとめてください。
```

手順が箇条書きで出てきます。ここではまず「素材を出す」段階です。
この時点では内容を信じきらず、次のステップで確かめます。

> AIが出した情報をそのまま使わない。「まず出す→次に確かめる」の2段構えが大事です。
{: .prompt-tip }

### ② 同じチャット内でファクトチェック

続けてすぐに投げました。

```
ファクトチェックして
```

**ハルシネーション（AI特有の誤り）:** AIが自信満々に事実と異なる情報を生成してしまう現象。設定手順のような「バージョン依存」の内容では特に起きやすいです。

修正提案がいくつか出てきたので、それを反映して再まとめを依頼しました。

### ③ ファクトチェック済みの内容で再整理

```
修正を踏まえて、再度まとめ直してください。
```

これで「確かめた素材」が完成しました。次はここから図解を作る工程に移ります。

### ④ スーパーエージェントで図解化

**スーパーエージェント:** GenSparkの自律型AI機能。プロンプト1つで検索・整理・デザインなど複数の作業を自動実行してくれます。

③の内容をコピーし、スーパーエージェントに貼りつけて実行しました。

```
以下の内容を元に、設定ガイドを図解してください。
[③のまとめをここに貼る]
```

ビジュアルとして整形されたガイドが生成されました。

### ⑤ 図解を「LINEで送れる形」に微調整

```
以下の3点で修正してください。
・専門用語を使わない
・LINEで送りやすいように
・スマホ版とパソコン版にわけて
```

> 「LINEで送りやすく」という制約を先に渡すのがポイントです。仕上がりが想定外に大きい画像になるのを防げます。
{: .prompt-tip }

### ⑥ LINE添付用のメッセージ文を生成

```
家族にLINEで送る前提で、この画像に添える短い説明メッセージを3パターン作ってください。
```

3パターン提案されたうちの1つを選び、軽く手直しして送信しました。

電話説明より早く、より正確に、より丁寧に届けることができました。

## ADS的な気づき

今回の作業を振り返ると、AIに対して「一発で完璧な答えを求めない」という設計が機能していました。

①で素材を出す → ②でズレを確かめる → ③で整える → ④⑤で形にする → ⑥で言葉を添える。

これはADSで学んでいる「プロセス分解」そのものです。一つひとつのプロンプトは単純でも、**順番と意図**があれば精度が上がります。

支援の仕事も同じ構造だと気づきました。相手の状況を一度に解決しようとせず、段階を踏んで整理していく——AIの使い方と支援の構造は案外似ています。

また「受け取る人がITに不慣れで、LINEで届ける」という**出口の制約**を最初から意識したことで、内容の粒度と形式が自然に絞れました。AIに渡す情報は多いほどいいわけではなく、**「誰に、どう届くか」を先に決めておく**方が結果が早いです。

## この記事で出た用語

💡 **OHOポイント:** 「出口（受け取る人・届け方）」を最初に決めておくと、AIへの指示が自然と絞られ、手戻りが激減します。

## この記事でわかること

- CursorのProとTeamで体感のクレジット消費差が生まれる**構造的な理由**
- Autoモードで使う財布がプランによって別設計になっている話
- 「言えること」と「断言してはいけないこと」の線引き

## こんな人向け

CursorをProまたはTeamプランで使っていて「なんかTeamのほうがクレジットの減りが早くない？」と感じたことがある人。

## 前提

- 使ったツール: Cursor（Pro / Teamプラン）、Dia（AI検索）、GenSpark（ファクトチェック）
- OS / 環境: 特定OSに依存しない（Cursorの課金構造の話）
- 課題フェーズ: 個人的なリサーチ・調査

---

## 体感から始まった疑問

CursorをProとTeamの両方で使う機会があり、気になることがありました。

「Teamプランのほうが、クレジットの減りが早い気がする」。

同じAutoモードで同じような会話量のはずなのに、なんか違う感覚があります。気のせいかとも思いましたが、何度やっても同じ印象。そこでDia（AI検索ツール）に直接聞いてみました。

> 「CursorのTeamプランと個人のProプランで、モデルAutoでチャットをした場合、体感のトークン消費量が違うのは何か根拠はありますか」

さらにGenSparkでクロスチェックを重ねたところ、**体感差には構造的な根拠がある**ことがわかりました。

---

## 鍵は「財布の数と設計」が違うこと

Cursorのクレジットには"財布"が複数あり、プランによってAutoモード使用時にどの財布から引き落とされるかが異なります。

### Autoモードで使う財布がプランで別

| | Pro | Team |
|---|---|---|
| Autoモード使用時 | **Auto専用プール**から消費。$20のAPIクレジットは**一切減らない** | **$20統合プール**から消費。Autoを使っても同じ財布が減る |
| 特定モデル使用時 | $20 APIプールのみ消費 | $20統合プール ＋ **Token Fee** が上乗せされる |

Proは"財布を2つ持っている"状態です。Autoモードを使うぶんには、$20のAPIクレジットに手をつけない設計になっています。
Teamは財布が1つで、AutoでもSpecificモデルでも同じ残高から出ていきます。

> Autoモードを多用するなら、Proは$20のAPIクレジットをかなり温存できる構造になっています。
{: .prompt-tip }

### Token Feeの存在も見逃せない

**Token Fee:** TeamプランでAIモデルを指定して使った際に上乗せされる追加料金。現行で+$0.25/Mトークン程度。Proにはこれがありません。

同じモデルを同量使っても、Team側だけ余分にコストが乗ります。同じ使い方でも$20の減り方に差が出るのは当然といえます。

### 総容量の非対称性

```
Pro（$20/月）：Auto専用プール（金額非公開）＋ $20 APIプール
Team（$40/月）：$20統合プール のみ（AutoもSpecificも同じ財布）
```

月額コストはTeamが2倍なのに、実質使えるバジェット総量はProのほうが多い構造になっています。

---

## ただし「言いすぎ」はNG——留保点も整理する

ファクトチェックで同時にわかったのは、「断言できないこと」もあるという点です。正直に書き残しておきます。

**Auto専用プールの金額は非公開**  
公式ドキュメントには「generous included usage」としか記載がありません。具体的な金額が出ていないため、「Proのほうがどれだけ余裕があるか」の定量的な比較は現時点では不可能です。

**使い方によって差の大きさは変わる**

| ユーザータイプ | 体感差 |
|---|---|
| Autoのみ使用 | 差は小さめ（ただしTeamは$20を消費する点で不利） |
| Auto＋特定モデル混合 | **差が最大**。Proは$20を温存できるがTeamは両方から削られる |
| 特定モデルのみ使用 | Token Fee分だけTeamが割高 |

**実際の消費トークン数の定量データは存在しない**  
公式のA/B比較データは提供されていないため、「体感差がある」はあくまで**構造から導いた推論**にとどまります。

> 「ProはTeamより必ずトークン消費が少ない」は言いすぎです。正確には「なぜそう感じるかは構造的に説明できる」が誠実な表現です。
{: .prompt-warning }

---

## 結論：体感は正しい。ただし「条件付き・推論ベース」

今回のリサーチで確認できたことをまとめます。

| 主張 | 言えるか |
|---|---|
| Proは実質的な総バジェットがTeamより多い | ✅ 構造的に言える |
| Autoモード使用時に$20が減らないのはProだけ | ✅ 公式確認済み |
| 特定モデルを使う場合、TeamはToken Fee分だけ割高 | ✅ Token Feeの存在から言える |
| 「体感でクレジットの減りが遅い」は合理的に説明できる | ✅ 上記3点から導出可能 |
| 実際に消費トークン数が統計的に少ない | ❌ 定量データがなく断言不可 |

使い方がAutoモード中心であれば、Proプランの"財布2つ"設計の恩恵を大きく受けられます。
「なんか減るの早い」という体感は、気のせいではなく**構造の違いで説明できる**ものでした。

## 再現手順（3ステップ）

1. 自分の"体感"をそのまま言語化してAIに問う（「なぜ○○と感じるか、根拠はあるか？」）
2. 出てきた仮説を別のAIツール（GenSparkなど）でクロスチェックする
3. 「言えること」と「言えないこと」を分けて記事に残す

## この記事で出た用語

| 用語 | 一行定義 |
|---|---|
| Autoモード | CursorがAIモデルを自動選択するモード。手動でモデルを指定しない状態。 |
| APIプール | プラン内で使えるAPI呼び出しのクレジット残高。プランによって設計が異なる。 |
| Token Fee | Teamプランで特定モデルを使用した際に上乗せされる追加料金（+$0.25/Mトークン）。 |
| generous included usage | 公式ドキュメントにおけるAuto専用プールの表現。具体的な金額は非公開。 |

💡 **OHOポイント:** 「体感の違い」はAIに構造から問えば証明できます——数字がなくても、設計の差は事実として語れます。
